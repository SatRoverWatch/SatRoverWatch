# Contributing to SatRoverWatch

Thanks for your interest in SatRoverWatch!

SatRoverWatch is an open-source Amateur Radio satellite project built around experimentation, field testing, and community ideas. You do not need to be a programmer to contribute.

## Suggest a feature

Have an idea for something SatRoverWatch could do?

Open an Issue and choose **Feature request**. Describe the idea in your own words and why you think it would be useful. You do not need to know how the feature would be implemented.

## Report a bug

If SatRoverWatch does something unexpected, open an Issue and choose **Bug report**.

Describe what happened, what you expected to happen, and any other information that may help reproduce or investigate the problem.

## Contribute code

Code contributions are welcome.

1. Fork the SatRoverWatch repository.
2. Make and test your changes in your fork.
3. Submit a Pull Request describing what you changed and why.

Small improvements, documentation corrections, and cleanup are welcome along with larger features.

## Field testing and feedback

Real-world rover testing is especially valuable. Reports about APRS behavior, grid transitions, satellite pass predictions, maps, weather information, alerts, and other rover experiences can help improve the project.

General feedback and suggestions from the Amateur Radio Satellite Community are welcome.

## Protect private information

Never include API keys, passwords, access tokens, private credentials, private rover configuration, or other sensitive information in an Issue, Pull Request, commit, screenshot, or log.

Before submitting logs or configuration excerpts, review them carefully and remove any sensitive information.

## Questions

If you are unsure whether something is a bug, feature request, or contribution, opening an Issue is fine. We can figure it out from there.

Thanks for helping experiment with and improve SatRoverWatch!
